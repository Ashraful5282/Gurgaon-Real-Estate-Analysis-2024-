# Gurgaon-Real-Estate-Analysis-2024-

🚀Data Analytics Project | Gurgaon Real Estate Analysis (2024)**

A Data Analytics project, where I explored the **Gurgaon Real Estate Dataset (2024)** from Kaggle using Python.

The main objective of this project was to explore raw real estate data, clean and preprocess it, and extract meaningful insights by answering some real-world business questions.

📊 **Key Questions I Explored:**
🔹 Which is the costliest flat in the dataset?  
🔹 Which locality has the highest average property price?  
🔹 Which property has the highest price per square foot?  
🔹 Do ready-to-move properties cost more than under-construction properties?  
🔹 Do RERA-approved properties command a price premium?  
🔹 How does property area (sqft) impact its price?  
🔹 Which BHK configuration is the most expensive on a per-square-foot basis?  
🔹 Which property type (Apartment, Floor, or Plot) is the costliest?  
🔹 Do certain builders or companies consistently charge higher prices?  
🔹 Are larger homes always more expensive per square foot?

🛠️ **Tools & Technologies Used:**
- Python
- Pandas – Data Cleaning and Data Manipulation
- Matplotlib – Data Visualization
- Seaborn – Statistical Data Visualization

💡 **Key Learning Outcomes:**

Through this project, I gained hands-on experience in:
- Cleaning and handling raw CSV datasets using Pandas.
- Identifying and handling inconsistent and missing values.
- Performing exploratory data analysis (EDA).
- Applying analytical techniques to answer real-world questions.
- Creating meaningful visualizations to communicate insights.
